🤖 Vibe Coding com Claude Code

Para quem já programa: Claude Code é como ter um copiloto sênior. Plan mode, workflow Git, anti-padrões. Aqui você aprende a multiplicar sua produtividade.

1

🧠 Plan Mode (Shift+Tab) — O Diferencial

A maior frustração com IA pra codar é "ela mexeu em arquivo errado e quebrou tudo". O Plan Mode resolve isso: Claude lê o código, monta um plano detalhado, e só executa depois da sua aprovação.

⚡ Como ativar

  1. Digita o que quer fazer ("adiciona auth com email/senha")
  2. Aperta Shift+Tab para entrar em plan mode
  3. Claude pesquisa o código, analisa, devolve plano
  4. Você revisa, aprova (ou ajusta), Claude executa

📊 Diferença que faz

Sem plan mode: 30% das vezes Claude mexe em coisa errada. Com plan mode: você pega problema antes da execução. Custo: 30 segundos de revisão. Benefício: horas economizadas.

2

🔄 Workflow: Pesquisa → Planeja → Implementa

Esse é o loop ideal. Não pula etapas. Quem pula direto para "implementa" gasta 3x mais tempo depois corrigindo.

1

Pesquisa

Claude lê arquivos relevantes, entende a estrutura, identifica dependências. Tempo: 30s-2min.

2

Planeja

Devolve um plano: quais arquivos vai mexer, o que vai mudar, riscos. Você revisa em 30s.

3

Implementa

Após aprovação, executa. Você acompanha em tempo real.

3

⚙️ Setup Básico

Setup é trivial. A barreira para usar IA pra codar é cultural, não técnica.

Instalação (1 comando)

npm install -g @anthropic-ai/claude-code

Uso (em qualquer projeto)

cd seu-projeto/
claude

Pronto. Conversa com Claude no terminal. Suporte a Git, MCP servers, hooks.

💡 Funciona com qualquer IDE

Claude Code roda no terminal, então combina com VS Code, Cursor, Vim, qualquer setup. Você não precisa abandonar suas ferramentas.

4

🪟 Cursor e Windsurf — Alternativas IDE

Para quem prefere interface gráfica em vez de terminal, existem 2 IDEs que valem conhecer.

Cursor

  • • IDE robusta com IA integrada
  • • Autocomplete contextual potente
  • • Pago: US$ 20/mês
  • • Bom para projetos grandes

Windsurf

  • • Free tier generoso
  • • Boa para iniciantes
  • • Codebase awareness profundo
  • • Ideal para começar sem investimento

⚡ Combo poderoso

Claude Code (terminal) + Cursor (IDE) podem coexistir. Use Cursor para edição comum, Claude Code para tarefas complexas que precisam de pesquisa profunda no código.

5

🚫 Anti-Padrões: Quando NÃO Usar IA

"Vibe coding" sem entender o código gera dívida técnica enorme em 6 meses. Saber quando NÃO usar IA é tão importante quanto saber quando usar.

✓ Use IA para

  • • CRUD repetitivo
  • • Telas/componentes padrão
  • • Refatoração simples
  • • Testes unitários
  • • Tradução de stack (ex: jQuery → React)

✗ NÃO use IA para

  • • Sistemas críticos sem testes
  • • Código que você precisa entender profundamente
  • • Lógica de negócio muito específica
  • • Segurança avançada
  • • Decisões arquiteturais

⚠️ A regra de ouro

Use IA para 80% repetitivo. Os 20% críticos: você lê, entende, escreve à mão. Sem isso, em 6 meses você tem código que ninguém entende — nem você, nem Claude, nem outro dev.

6

🌿 Fluxo Git Que Funciona com IA

Git e IA combinam perfeitamente — desde que você siga uma regra simples: commits pequenos e frequentes. Quando IA quebra algo, você reverte 1 commit, não a tarde inteira.

📋 Workflow recomendado

  1. Cria branch para feature: git checkout -b feature/auth
  2. Pede pra Claude implementar 1 coisa pequena
  3. Revisa diff: git diff
  4. Se OK: commit imediato com mensagem clara
  5. Se não OK: descarta com git restore . ou ajusta
  6. Próxima tarefa pequena, ciclo repete

⚡ Granularidade ideal

Cada commit = 1 mudança lógica. "Adicionar login com email" = 1 commit. "Adicionar reset de senha" = 1 commit. Nunca "implementei autenticação inteira" = 1 commit gigante.

💡 Mensagens de commit

Claude pode escrever as mensagens para você no padrão Conventional Commits (feat, fix, refactor, etc). Pede e ele faz.
