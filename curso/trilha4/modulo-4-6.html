MÓDULO 4.6

🌱 Distribuição Sem Pagar Influencer

SEO, ASO, reviews, comunidade, indicação. Os canais orgânicos que custam tempo, não dinheiro — e compõem juros.

1

🔍 SEO/ASO Básico

Otimização de palavras-chave para aparecer em buscas. Site = SEO. App = ASO (App Store Optimization).

Estratégia mínima

  • • Identifica 3 palavras-chave alvo (use Google Keyword Planner ou similar)
  • • Inclui no título, descrição, primeira frase do conteúdo
  • • Para apps: incluir nas screenshots, vídeo de preview, descrição
  • • Atualize trimestralmente

📊 Por que vale o tempo

Tráfego orgânico custa tempo, não dinheiro. E composta. SEO bom hoje rende 1-2 anos depois sem você fazer nada.

2

⭐ Reviews Como Ativo

Reviews 4-5 estrelas são prova social. Sem reviews, novo usuário hesita. Com 100+ positivas, decisão é fácil.

Quando pedir review

A regra: após momento de sucesso, nunca antes.

  • • Após 3 dias usando consistentemente
  • • Após o usuário completar tarefa principal
  • • Após resultado positivo (perdeu peso, fechou venda, terminou tarefa)
  • • NUNCA nos primeiros minutos do uso

✓ Como pedir

Diálogo dentro do app: "Tá funcionando pra você? Se sim, deixa uma review — ajuda muito a galera nova nos achar." Casual, não burocrático.

3

👥 Comunidade Como Motor

Discord, Telegram, WhatsApp. Onde usuários conversam entre si sobre o produto. Vira motor de retenção e crescimento.

📊 Por que funciona

  • • Usuário que conversa com outros usuários cancela menos
  • • Comunidade vira fosso competitivo (concorrente novo não tem)
  • • Membros respondem dúvidas entre si — reduz seu suporte
  • • Conteúdo gerado pelos usuários vira marketing orgânico

Razão de entrar

Tem que ter razão pra entrar. Senão, fica vazio. Opções: desconto exclusivo, conteúdo bônus, suporte direto, networking entre clientes.

4

🎁 Programa de Indicação (Referral)

"Indica 1 amigo, ganha 1 mês grátis." Estrutura simples que transforma cliente satisfeito em distribuidor.

Estrutura que funciona

  • • Recompensa para AMBOS (quem indica E quem é indicado)
  • • Recompensa imediata, não "depois de 90 dias"
  • • Compartilhamento simples (1 link único, copiar e colar)
  • • Ativa só após o cliente ter sucesso, não no dia 1

📊 Por que vale

CAC via referral é fração do via ads. Cliente indicado tem retenção MAIOR que cliente "pago". Dropbox cresceu 3.900% em 15 meses com programa de referral.

5

⚙️ Rodas de Crescimento (Loops)

Mecanismos onde uso gera mais uso. WhatsApp (você usa porque amigos usam). Dropbox (compartilha gera novo signup). Funciona 24/7 mesmo enquanto você dorme.

Pergunta-bisturi

"Qual ação do meu usuário pode trazer outro usuário?"

Embute essa ação no produto. Cada uso vira semente de novo uso.

Exemplos clássicos

  • • Calendly: usuário compartilha link de agendamento → outro precisa criar conta para agendar
  • • Loom: usuário grava vídeo → compartilha → quem assiste sobe para fazer próprio vídeo
  • • Notion: usuário compartilha página → outros se inscrevem para colaborar
6

⏰ Quando Começar (Resposta: Ontem)

Canais orgânicos demoram 3-12 meses para render. Quem começa agora colhe daqui a meses. Quem espera, fica eternamente refém de ads.

A trap do "começar quando crescer"

"Vou fazer SEO quando tiver mais tempo." → SEO leva tempo pra render. Quando você "tem tempo," já perdeu meses.

Comece antes de precisar.

✓ Plano semana 1 do MVP

  • • Configurar Google Analytics e UTMs
  • • Criar grupo de comunidade (mesmo vazio)
  • • Definir programa de indicação básico
  • • Otimizar SEO/ASO inicial
  • • Primeira página de blog/conteúdo (sementes)

✓

✓

✓
